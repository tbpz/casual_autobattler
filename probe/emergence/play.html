Pick 5 of the 15 soldiers below — you can't take them all, so which 5 (and what order) is a real decision. Some tokens act on their own turn; some only react when another token triggers an event (hit / crit / kill). A reaction can trigger another reaction — a chain. A few tokens have real cost or only work in one slot — they can make a build worse, not just add to it.
The test: before you hit Play, guess the score out loud. Then watch. The gap between your guess and the real number is the whole thing we're testing.
How to read a token: TURN = does this on its own turn. ON = reacts whenever anyone shouts that event. HIT CRIT KILL — one event can wake several tokens at once → a chain. Some tokens consume the event they react to, so later reactors miss it.
