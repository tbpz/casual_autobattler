# Bets

> **Last updated:** 2026-10-23
> Every bet serves one pillar. A bet that serves none widens the game, it does not deepen it.
> A decision that breaks a verified bet is flagged to Tu before it is logged, never applied silently.

## The top test

Someone not on the team finishes a run and starts another without being asked. (Unverified, ranked 7 below.)

## Pillars

- **A. The fight moment** — "It blew up bigger than I expected, and I made that happen."
- **B. The run** — "My choices in this run mattered."
- **C. Coming back** — "One more run; the next one will be different, and I keep getting better."
- **D. Pick up and play** — "I got it in minutes on my phone, and a run fits my sitting."

## Verified — the quality standard

### A. The fight moment

- The lead moment lands in plain runs. — [2026-10-23][1]
- Rune synergy is the strongest source of "mine"; chain luck is the lesser. — [2026-10-23][1]
- Runes must combine with what the squad's skills do. — [2026-10-23][2]
- Chains run unexpectedly long both ways; payoff and backfire both surprise. — [2026-08-17][3]
- A player can name what caused a chain. — [2026-08-25][4]
- The big payoff is rare; one every fight feels scripted. — [2026-08-06][5]
- Spectacle plays only when the payoff is real. — [2026-08-06][6]
- Every HP loss has a visible actor and cause. — [2026-08-04][8]
- RNG alone fails "claim as mine". — [2026-07-26][14]

### B. The run

- The best squad can still lose. — [2026-08-08][7]
- A run grows as it goes; it never only shrinks. — [2026-09-23][9]
- A run never ends on something the player could not change. — [2026-09-23][10]
- A real decision brings new options, never leaves the default better, never collapses to one move. — [2026-07-26][11]
- Watching with no real choice reads as an idle game. — [2026-10-17][15]
- A re-skin alone gives an army no identity. — [2026-10-21][16]
- An army's own runes must act on its own mechanic; a rune that works with the army taken out gives no identity. — [2026-10-23][18]

### C. Coming back

- Chance alone stops holding Tu once the best move is known. — [2026-07-24][12]
- A solved deterministic build stays solved. — [2026-07-22][13]

### D. Pick up and play

- A term is explained where the player first meets it. — [2026-10-10][17]

## Unverified — verify in this order

2. [A] The same works for the Undead and Beasts.
3. [B] An army gives a run an identity worth picking.
4. [D] Skeletons, the pounce and orbs stay readable on a phone.
5. [B] Push or rest stays a real choice; tired units get benched by hand.
6. [D] A first-time player reads the game unprompted.
7. [Top] Someone not on the team finishes a run and starts another without being asked.
8. [D] A new player wins about 1 run in 4.
9. [C] A player starts another run right after one ends, win or lose.
10. [C] Run 20 still shows something new.
11. [D] A run fits a short sitting.
